Cadastrar usuário

Abas que a pessoa vê:

Leitor só consulta. Editor altera simulações e importa notas, vendas e estoque. Master faz tudo e gerencia usuários. Administrador do sistema também cuida de backup e configurações. Usuário desativado não consegue entrar.

Atualizar base

Envie um novo arquivo base_inicial.json quando a planilha Geral ou as estruturas forem atualizadas. As simulações, notas, vendas e estoque já salvos continuam.

Configurações · Backup

Backup completo no seu computador

Baixa um arquivo .zip com a base, as simulações, notas, vendas, estoque, usuários e todos os XMLs. Guarde fora do sistema (pasta do computador, Google Drive). Recomendado: uma vez por semana.

Cópias automáticas no banco

Todo dia às 03:00 o sistema guarda uma cópia da base, simulações, notas, vendas e estoque (os XMLs não mudam, por isso ficam fora). São mantidas as últimas 14 cópias automáticas.

Restaurar de um arquivo de backup

Use só se precisar recuperar o sistema (por exemplo, num projeto novo). Substitui a base, simulações, notas, vendas, estoque e XMLs pelo conteúdo do arquivo. Antes, uma cópia do estado atual é guardada automaticamente. Os usuários não são recriados.
